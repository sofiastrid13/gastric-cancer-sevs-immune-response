# Protein Analysis

This folder contains experimental data and supporting records from protein analysis and small extracellular vesicle (sEV) characterization in plasma samples from healthy controls (HC), patients with chronic gastritis (CG), and patients with gastric cancer (GC).

## Files

| File | Description |
| --- | --- |
| `BCA.xlsx` | Protein quantification data obtained using the bicinchoninic acid (BCA) assay. The **BCA** worksheet organizes measurements by clinical group and sample, including fraction-level replicate values. The **BSA Standard Curve** worksheet provides bovine serum albumin (BSA) standards, absorbance replicates, and calibration information used for protein quantification. |
| `DOT BLOT.xlsx` | Sample-level dot blot records for the detection of sEV-associated tetraspanin markers, CD81, CD63 and CD9, with columns for results. |

## Purpose

The spreadsheets document complementary aspects of sEV characterization:

- **BCA assay:** Evaluation of protein concentration across samples and fractions using a BSA calibration curve.
- **Dot blot:** Documentation of immunodetection of selected sEV-associated markers to support sample and fraction characterization.

## Data organization and interpretation

Sample identifiers and clinical group labels are retained as recorded in the original spreadsheets. Technical replicates and fraction identifiers should not be treated as independent biological samples. Consult the relevant worksheet labels, calibration information, and experimental methods before interpreting values or comparing groups.

## How to use

1. Open `BCA(1).xlsx` to review protein measurements and the BSA standard curve.
2. Open `DOT BLOT(1).xlsx` to review the dot blot marker records and associated results.
3. Cross-reference sample identifiers with other datasets in the repository where applicable.

## Notes

These files provide supporting experimental records. The dot blot results should be interpreted as marker detection evidence, not as a standalone quantitative measure of sEV purity or abundance.
