# Supplementary Material

This repository contains the supplementary tables associated with the study on small extracellular vesicles (sEVs), cytokines, and immune checkpoints in gastric cancer.

The repository was created to facilitate access to the supplementary material during manuscript and thesis review. Each supplementary table is provided in accessible formats, including PDF and Excel files.

## Supplementary Tables

| Table | Description | Files |
|------|-------------|-------|
| [Supplementary Table S1](./Table%20S1/) | Spearman correlation analysis among soluble immune checkpoint molecules in PBMCs according to clinical group and time point. | PDF and XLSX |
| [Supplementary Table S2](./Table%20S2/) | Stage-specific Spearman correlations between immune checkpoint concentrations in PBMCs stimulated with sEVs and their corresponding concentrations in isolated sEVs. | PDF and XLSX |
| [Supplementary Table S3](./Table%20S3/) | Stage-specific Spearman correlations among cytokines at their peak response times in PBMCs stimulated with sEVs. | PDF and XLSX |
